# MetroBI

Power BI custom visuals:

| Folder | Visual |
| --- | --- |
| [MetroMap](MetroMap/README.md) | Leaflet maps (WMS, GeoJSON, shapefile) |
| [MetroKit](MetroKit/README.md) | xeokit 3D viewer (XKT, glTF, IFC, NavCube) |

```powershell
cd MetroMap
npm install
npx pbiviz package

cd ..\MetroKit
npm install
npx pbiviz package
```
